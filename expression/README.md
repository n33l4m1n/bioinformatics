# Expression: reprogramming and aging

**Planned. Nothing is implemented yet.** Part of the [bioinformatics verticals](../README.md).

Reproducible analysis of measured cell states, such as somatic cells against reprogrammed or aged cells, from
public processed datasets. Every result will report effect sizes and uncertainty, and every dataset will be pinned
by accession, version and checksum.

The [sequence toolkit](../sequence/README.md)'s bundled FASTA files are parser examples, not inputs for this work:
sequence composition does not measure expression, methylation or biological age.
