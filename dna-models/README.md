# DNA models: small-model evaluation

**Planned. Nothing is implemented yet.** Part of the [bioinformatics verticals](../README.md).

Evaluation of small DNA sequence models that fit a single consumer GPU (6 GB), against conventional baselines on
tasks with known labels. Each evaluation will record the exact checkpoint, tokenizer, license and precision, and
measure accuracy, runtime, VRAM, power and temperature alongside the scores.
